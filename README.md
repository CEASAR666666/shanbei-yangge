# 红绸入陕北

这是一个不依赖构建工具的网页原型，已包含手机版/电脑版入口、秧小北助手、音乐房和本地头像工坊。直接双击 `index.html` 即可预览；如果浏览器对本地图片、音频或字体有限制，可在当前目录运行：

```bash
python3 -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。

图片素材均已放入 `assets/`，页面底部“资料来源与使用说明”列出公开来源与许可信息。音乐房中的公版音频为 `assets/audio/chinese-ensemble.ogg`；其余节拍为本地合成试听音，不冒充真实民歌录音。
